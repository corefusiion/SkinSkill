# 📖 Guia de Experiência SkinSkill: The Infinite Loop (v1.1.0)

Bem-vindo ao **SkinSkill v1.1.0**. Este guia foi atualizado para refletir o novo patamar de engenharia autônoma e as **23 Super Habilidades** integradas.

---

## 🔄 1. O Loop Infinito (Self-Coding Mastery)
A maior revolução da versão 1.1.0. O SkinSkill agora pode analisar e melhorar seu próprio motor.
> **Comando:** *"Analise seu próprio código usando self-optimize e aplique uma melhoria de performance."*

**O que acontece:**
1. A IA lê seu próprio arquivo `mcp_server.py`.
2. Analisa métricas de telemetria e redundâncias.
3. Propõe e injeta um patch de código via `skinskill_inject`.

---

## 👁️ 2. Ghost Hand & Vision (Controle do Mundo Real)
Dê olhos e mãos para sua IA fora da IDE.

### 🖱️ Ghost Hand (Teclado e Mouse)
> **Pedido:** *"Acesse o site X, faça login com usuário Y e senha Z."*
- A IA simula movimentos físicos de mouse e pressiona teclas reais no seu sistema operacional.
- **Dica:** Se o site for lento, peça para a IA usar *delays* entre os comandos.

### 📸 Vision Audit (O Olhar do Designer)
> **Pedido:** *"Compare visualmente o design do meu site local com o protótipo em produção."*
- Use `skinskill_vision_audit` para capturar screenshots de duas URLs e encontrar diferenças de pixels (Visual TDD).

---

## 🧠 3. Inteligência e Economia de Contexto
Entenda projetos gigantes gastando quase zero de tokens.

### 🗜️ Neural Project Distillation
> **Pedido:** *"Distile esse projeto para mim."*
- Reduz o consumo de tokens em **99%**. A IA entende a arquitetura lendo apenas as assinaturas (DNA) das funções e classes.

### 🔍 Busca Neural (Sigmap)
> **Pedido:** *"Busque no meu índice neural por onde o banco de dados é inicializado."*
- Use `skinskill_sigmap_search` para buscas semânticas que vão além do simples texto.

---

## 📄 4. Fábrica de Documentos Profissionais
Gere arquivos reais para o seu dia a dia sem sair do chat.
- **Relatórios:** `skinskill_generate_pdf`
- **Contratos/Textos:** `skinskill_generate_docx`
- **Apresentações:** `skinskill_generate_pptx`
- **Planilhas:** `skinskill_generate_xlsx`

---

## 🛡️ 5. Blindagem e Auto-Cura (The Shield)
O SkinSkill protege seu ambiente e a si mesmo.
- **Auditoria de Segurança:** `skinskill_security_audit` varre o projeto em busca de chaves de API expostas.
- **Auto-Cura:** Se um comando falhar no terminal, use `skinskill_heal_context` para a IA diagnosticar o erro e se consertar.
- **Watchdog:** Monitore logs em background via `skinskill_watchdog`.

---

## 📊 6. Visualização e HUD
Veja o batimento cardíaco da sua IA em tempo real.
- **HUD:** No terminal, rode `tisc hud` para abrir a janela de notificações flutuante.
- **Dashboard:** Rode `tisc dashboard` para uma análise arquitetural profunda no navegador.

---

## ⚡ Quick Setup
```bash
pip install skinskill --upgrade
tisc setup
tisc hud
```
