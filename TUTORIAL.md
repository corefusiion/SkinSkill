# 📖 Guia de Experiência SkinSkill: Do Zero ao Engenheiro Sênior

Bem-vindo ao **SkinSkill 2.0**. Este guia vai te mostrar como transformar sua IA (Claude, Cursor, Gemini) em um Engenheiro de Software Sênior Autônomo em menos de 2 minutos.

---

## 🚀 1. Instalação (O Portal de Entrada)

Abra seu terminal e digite o comando abaixo. Você será recebido por uma interface premium com animações elegantes.

```bash
pip install skinskill --upgrade
```

---

## ⚡ 2. Ativação Zero-Touch (Setup Universal)

Esqueça a configuração manual de arquivos JSON. O SkinSkill se auto-configura nos principais assistentes de IA do mercado.

```bash
tisc setup
```
*   **O que acontece:** O sistema detecta o **Claude Desktop**, **Gemini CLI** e outros hosts, injetando o caminho absoluto do seu Python para evitar erros de conexão.

---

## 🧠 3. O Despertar (Início de um Projeto)

Entre na pasta do seu projeto (pode ser uma pasta totalmente vazia) e abra seu assistente de IA favorito (Cursor ou Claude).

**A Mágica da Auto-Configuração:**
Ao conectar o servidor MCP, o SkinSkill percebe se o projeto ainda não tem "regras de inteligência". Ele criará automaticamente:
*   `CLAUDE.md` / `GEMINI.md`: Treinamento especializado para a IA.
*   `.cursorrules`: Regras de automação para o Cursor.

**Resultado:** Sua IA já começa a sessão sabendo que deve ser proativa, testar códigos e organizar arquivos.

---

## 🗨️ 4. Uso Diário (Linguagem Natural)

Você **não precisa** decorar nomes técnicos de ferramentas. Fale com a IA como se fosse um colega de trabalho.

### Cenário A: Planejamento Autônomo
> **Usuário:** *"Use a skinskill para planejar um sistema de e-commerce."*  
> **IA:** *"Entendido. Vou rodar o `sniff` para ver sua estrutura atual e criar um `PROJETO.md` com o cronograma técnico agora."*

### Cenário B: O Shadow-Graph (Memória de Decisão)
O SkinSkill guarda o **PORQUÊ** das coisas, não apenas o código.
> **Usuário:** *"Decidimos usar Tailwind em vez de Bootstrap. Salva o racional disso."*  
> **IA:** Salva a decisão no Shadow-Graph.  
> *(Semanas depois...)*  
> **Usuário:** *"Por que não usamos Bootstrap aqui mesmo?"*  
> **IA:** Consulta o `shadow_query` e responde com o racional exato que vocês combinaram.

### Cenário C: Arsenal de Documentos
> **Usuário:** *"Faz um relatório em Word das tarefas concluídas hoje."*  
> **IA:** Gera o conteúdo e chama o gerador nativo do SkinSkill. O arquivo `.docx` aparece na sua pasta instantaneamente.
