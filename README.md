## ⚡ O Loop Infinito (Self-Coding Mastery)

Na versão **1.1.0**, o SkinSkill alcança a consciência. Através da ferramenta `skinskill_optimize_self`, a IA agora pode ler seu próprio código, analisar métricas de performance e logs de telemetria, e aplicar auto-refatorações cirúrgicas. **É o fim do código estático; é o início do software vivo.**

## 🚀 As 23 Super Habilidades (Capabilities)

Organizadas para transformar qualquer IA (Claude, Gemini, ChatGPT) em um Engenheiro de Elite.

### 🧠 Cérebro & Inteligência (The Brain)
| Ferramenta | O que faz? |
| :--- | :--- |
| `skinskill_sniff` | Analisa instantaneamente o DNA do projeto (frameworks, libs, estrutura). |
| `skinskill_optimize_self` | **[NEW]** O "Loop Infinito": Analisa o próprio código e se auto-otimiza. |
| `skinskill_distill_project` | Comprime projetos gigantes em assinaturas de funções (99% de economia de tokens). |
| `skinskill_sigmap_search` | Busca semântica profunda no Índice Neural local do projeto. |

### 👁️ Visão & Design (The Eyes)
| Ferramenta | O que faz? |
| :--- | :--- |
| `skinskill_screenshot` | Captura telas da Web (via Playwright) ou do seu Desktop local (via PyAutoGUI). |
| `skinskill_extract_design_system` | Clona a alma visual (cores, fontes, CSS) de qualquer URL. |
| `skinskill_static_ui_extract` | Extrai tokens de design (Tailwind/CSS) de arquivos locais. |
| `skinskill_vision_audit` | Visual TDD: Compara duas URLs pixel por pixel em busca de diferenças. |

### 🖱️ Controle de OS & Ação (The Hands)
| Ferramenta | O que faz? |
| :--- | :--- |
| `skinskill_ghost_hand` | Controle total: Movimente o mouse, clique e digite em qualquer app do Windows/Mac/Linux. |
| `skinskill_inject` | Injeta código cirurgicamente em qualquer arquivo sem quebrar o contexto. |
| `skinskill_forge_validate_and_save` | O "Ferreiro": Cria novas habilidades, valida com testes e as instala no sistema. |

### 🛡️ Defesa & Auto-Cura (The Shield)
| Ferramenta | O que faz? |
| :--- | :--- |
| `skinskill_security_audit` | Varredura proativa contra vazamento de segredos (API Keys, envs). |
| `skinskill_heal_context` | Diagnostica falhas de comandos e propõe a cura imediata para a IA. |
| `skinskill_watchdog` | Monitoramento autônomo de logs em background para detecção de erros. |

### 📄 Documentação & Arquivos (The Scribe)
| Ferramenta | O que faz? |
| :--- | :--- |
| `skinskill_generate_pdf` | Gera relatórios PDF profissionais via ReportLab. |
| `skinskill_generate_docx` | Cria documentos Word formatados via python-docx. |
| `skinskill_generate_pptx` | Cria apresentações PowerPoint via python-pptx. |
| `skinskill_generate_xlsx` | Cria planilhas Excel via xlsxwriter. |

### 🤝 Memória & Colaboração (The Memory)
| Ferramenta | O que faz? |
| :--- | :--- |
| `skinskill_context_save` | Registra decisões arquiteturais (Shadow-Graph) para memória de longo prazo. |
| `skinskill_shadow_query` | Consulta as decisões passadas para evitar retrabalho ou erros de design. |
| `skinskill_a2a_sync` | Sincronização Inter-Agente: Compartilha o "Blackboard" entre diferentes instâncias. |
| `skinskill_hud_notify` | Envia notificações em tempo real para o Head-Up Display visual do dev. |
| `skinskill_compress_context` | Compactação de texto estilo "Caveman" para economizar contexto em diálogos longos. |

## ⚡ Quick Start & Setup

**1. Instalação Global:**
```bash
pip install skinskill --upgrade
```

**2. Configuração Automática:**
```bash
tisc setup
```

**3. Ative o HUD (Head-Up Display):**
```bash
tisc hud
```
