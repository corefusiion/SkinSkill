## 🚀 O que é o SkillCode?

O **SkillCode** é um agente autônomo de IA projetado para rodar em seu terminal e atuar como um engenheiro de software de elite. Diferente de ferramentas estáticas, o SkillCode possui:

1. **Loop Autônomo de Raciocínio & Ação (ReAct)**: Ele analisa seus objetivos, executa comandos, lê/escreve arquivos e resolve problemas de forma proativa.
2. **Auto-Refatoração e Evolução (Auto-Forge)**: Sempre que se depara com uma tarefa para a qual não tem ferramentas específicas, ele cria uma nova extensão em Python sob a pasta `skins/`, valida-a usando testes (TDD) e a registra dinamicamente sem interromper o loop.
3. **Servidor MCP Integrado**: Expõe todas as suas 23+ super habilidades para qualquer IDE compatível com a especificação Model Context Protocol (MCP).
4. **Interface CLI Premium**: Interface estilizada em roxo, preto e branco com telemetria do sistema operacional no início de cada sessão.

## ⚡ Quick Start & Setup

**1. Instalação Global:**
```bash
pip install skillcode --upgrade
```

**2. Configuração do Agente:**
Configure suas chaves de API (OpenRouter, Gemini, Claude, etc.):
```bash
skc config
```

**3. Iniciar o Servidor MCP Embutido:**
Para conectar ao Cursor ou VS Code:
```bash
skc mcp start
```

**4. Ative o HUD (Head-Up Display) Visual:**
```bash
skc hud
```

**5. Comando Geral:**
Para ver a lista completa de comandos CLI:
```bash
skc --help
```
