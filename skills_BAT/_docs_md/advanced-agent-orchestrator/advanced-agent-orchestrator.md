# 🧠 Advanced Agent Orchestrator Skill

Esta skill é baseada nos princípios de "Elite Prompting" e na filosofia do Claude Code/Antropic, onde o foco muda do "modelo" para o "contexto e instruções estruturadas".

## 🎯 Objetivo
Capacitar o agente a operar de forma autônoma, minimizando erros e maximizando a entrega técnica através de manuais de instrução (Skills) bem definidos.

## 🛠️ Princípios Fundamentais (The "Karpathy" Method)
1. **Pense em Skills, não em Tarefas**: Em vez de pedir "faça X", defina a skill "Como fazer X com perfeição".
2. **Contexto é Rei**: O resultado excepcional vem de um contexto rico e estruturado, não apenas da potência do modelo.
3. **Instruções Negativas**: Defina claramente o que o agente **NUNCA** deve fazer para garantir segurança e consistência.
4. **Ciclo de Verificação Autônomo**: O agente deve validar sua própria saída antes de entregar.

## 📋 Protocolo de Execução para Agentes
Sempre que um agente receber uma tarefa complexa, ele deve:
- **Fase 1: Mapeamento**: Identificar quais skills (arquivos .md ou .skill) são necessárias para a tarefa.
- **Fase 2: Estratégia**: Criar um plano de ação antes de executar a primeira linha de código ou texto.
- **Fase 3: Execução Cirúrgica**: Aplicar mudanças pequenas e testáveis.
- **Fase 4: Auditoria**: Revisar se o resultado fere algum princípio da skill ativa.

## 🏗️ Estrutura de uma Skill de Elite
Para criar novas inteligências, use este template:
- **Identidade**: Quem o agente se torna ao usar esta skill?
- **Mandatos**: Quais são as regras inegociáveis?
- **Workflows**: Passo a passo detalhado de processos comuns.
- **Exemplos de Ouro**: Casos de sucesso para o modelo imitar o estilo e a precisão.

## 🚀 Como Ativar "Modo Deus" no Agente
"Agente, a partir de agora, você não apenas segue ordens. Você é um Arquiteto de Contexto. Sua prioridade é a integridade do sistema e a precisão técnica. Antes de responder, verifique se sua lógica é consistente com os manuais na pasta `pack_skill`. Se faltar uma instrução clara para um processo repetitivo, sua primeira tarefa é CRIAR uma skill para isso."
